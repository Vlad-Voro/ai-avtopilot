# 24/7 Telegram Бот и Шлюз Заявок на Cloudflare Workers

Данный воркер обеспечивает **бесперебойную работу связки 24/7**:
1. **Обработка обращений в боте @AiAvtopilotbot**: бот мгновенно приветствует клиентов, предлагает бесплатный аудит, пересылает контакты и сообщения администратору (@VlVoro, ID: `111288881`) и позволяет отвечать клиентам через кнопку **Reply**.
2. **Гарантированная доставка заявок с сайта ai-avtopilot.ru**: исключает блокировку `api.telegram.org` провайдерами в РФ, принимая запросы с фронтенда на `POST /submit`.

---

## Быстрый деплой за 2 минуты (через веб-интерфейс Cloudflare)

1. Зайдите в панель [dash.cloudflare.com](https://dash.cloudflare.com/) (бесплатный тариф).
2. В левом меню откройте **Compute (Workers & Pages)** → **Workers**.
3. Нажмите **Create application** → **Create Worker**.
4. Задайте имя, например `ai-avtopilot-bot`, и нажмите **Deploy**.
5. Нажмите **Edit code**.
6. Полностью замените код файла `worker.js` на содержимое соседнего файла [`worker.js`](worker.js).
7. Нажмите кнопку **Save and Deploy**.
8. Перейдите по ссылке активации вебхука в браузере:
   ```
   https://ai-avtopilot-bot.<ваш-субдомен>.workers.dev/set-webhook
   ```
   *(Вы увидите ответ `{"webhookUrl": "...", "result": {"ok": true, "result": true}}`)*

**Готово!** Бот теперь работает автономно в облаке, не требуя включенного компьютера или локального VPN.
