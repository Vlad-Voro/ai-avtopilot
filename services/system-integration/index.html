Часто задаваемые вопросы

Всё о безопасности 152-ФЗ, интеграции с 1С и регламенте пилотного запуска

Нет. Интеграция подключается через типовые механизмы расширений конфигурации (CFE) и OData REST API без снятия конфигурации с типовой поддержки.

Все компоненты интеграционной шины разворачиваются строго в закрытом серверном периметре заказчика (On-Premise) без передачи информации во внешние облачные сервисы.

Используется брокер сообщений с очередями гарантированной доставки. Все пакеты буферизуются и автоматически повторяют попытку отправки при восстановлении связи без потери данных.

Агент нормализации данных автоматически сопоставляет контрагентов по ИНН/КПП, а номенклатуру — по артикулам и штрихкодам с использованием алгоритмов нечеткого сравнения.

Развертывание первого рабочего интеграционного потока (например, заказы 1С <-> Битрикс24) занимает ровно 14 календарных дней под ключ.
